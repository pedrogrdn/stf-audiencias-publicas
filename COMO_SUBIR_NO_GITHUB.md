# Repositório público e integração posterior

O destino deste conteúdo é https://github.com/pedrogrdn/stf-audiencias-publicas . A publicação inicial está sendo feita separadamente do repositório privado de trabalho. Este diretório não contém o histórico Git privado, ambientes ou credenciais.

Antes de criar a primeira release, confirmar autoria e licenças, adaptar os metadados ao formato aceito e habilitar a integração no Zenodo somente para este repositório público. Commits comuns não geram depósitos; uma nova release habilitada inicia o arquivamento. Nenhuma release ou publicação no Zenodo foi criada nesta preparação.

Para conferir os dados e hashes localmente: `python3 reproduzir.py --verificar`. A reprodução estatística e os testes são descritos no README. A verificação não chama APIs.
